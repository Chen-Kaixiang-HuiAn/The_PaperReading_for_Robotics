# CrossTracer: Cross-Embodiment Navigation via VLA Model Reasoning and Trace Residuals Adapting

> 用归一化像素轨迹作统一接口——VLA 提语义轨迹，CE-Adapter 按具身残差修正，CE-RRT\* 自动造监督

## 一、概览

CrossTracer 解决 VLA 导航的「具身鸿沟」：同一指令与观测下，腿式与轮式机器人的可行路径不同，而端到端 VLA 把语义、具身约束与控制耦死在一个模型里。本文以归一化图像平面航点序列为中间表示：VL-Tracer（基于 OmniVLA 微调）输出与具身无关的初始语义轨迹，CE-Adapter 以机器人嵌入 + FiLM 调制预测残差修正；CE-RRT\* 把全景分割转成具身条件代价图、在像素平面跑 RRT\* 自动生成训练监督。NaviTrace 总分 45.68，超最强通用基线 Gemini-2.5-Pro 10.01 分（相对提升 28.1%）。

## 二、问题背景

VLA 模型为导航提供强语义先验，但输出往往未锚定于机器人-specific 运动能力（原文第 I 节）：腿式机器人可跨小台阶与碎石，轮式机器人必须绕行——语义上合理的路径对另一具身可能物理不可行。现有路线各有局限：端到端 VLA 策略将语义推理、具身约束与控制耦在同一策略中，难以把同一语义方案迁移到不同可通行性画像的机器人；分层方法（如 VAMOS）用 VLM 提候选路径再由具身 affordance 模型重排，但候选选择只能在有限提案集中挑，若所有候选都含不可行片段则无从补救；更根本地，训练具身感知的修正模型需要跨场景、跨平台的昂贵人工标注。

## 三、方法要点（论文复述）

**问题形式（第 III 节）**：给定自中心 RGB 观测 $I$、目标规格 $G$（语言 $L$、目标像素 $P_g=(x_g,y_g)$ 或两者）与具身 $e$，输出具身条件轨迹 $T_e=\{w_t\}_{t=1}^{N}$，$w_t=(x_t,y_t)\in[-1,1]^2$，$N=8$；归一化坐标提供分辨率无关接口，经 $u_t=\frac{x_t+1}{2}W$、$v_t=\frac{y_t+1}{2}H$ 转回像素。核心分解：$T_{init}=f_\phi(I,G)$（语义提案，不条件化具身），$T_e=T_{init}+\Delta T_e$，$\Delta T_e=g_\theta(I,T_{init},e)$（残差修正）。

**VL-Tracer（第 IV-B 节）**：基于 OmniVLA 架构，视觉/语言 token 与 MLP 投影的目标位姿 token 拼接为 $X_{input}=[X_V\|X_L\|X_P]$，缺失模态用掩码移除（训练时以 $p_{drop}=0.3$ 随机丢弃提升鲁棒性）；轨迹头 $\hat w_t=\tanh(\mathrm{MLP}_{head}(h_t))$ 约束在归一化坐标。在 VAMOS 轨迹数据上 LoRA 微调（主干冻结），损失为航点 L2 + 平滑项（$\lambda_{smooth}=0.01$）。

**CE-RRT\*（第 IV-C 节）**：免人工标注的规划器监督管线。Mask2Former（ResNet-50）全景分割后，按具身 $e$ 定义语义代价配置 $K_e=\{S^e_{free},S^e_{soft},\rho_e\}$（低代价可通行类 / 困难可通行类 / 软代价映射），得基础代价图；再对可通行区域做欧氏距离变换，惩罚靠近不可行像素的 $P_{ext}$、对不可行像素赋 $P_{int}$ 障碍惩罚，合成具身条件代价图 $C_e$。随后在 $H\times W$ 图像平面跑 RRT\*：目标偏置采样 $p_{goal}=0.15$、步长 $\Delta_{step}=25$ 像素、搜索半径 $r=60$ 像素、最大迭代 $N_{max}=10000$；路径代价 $J(P;C_e)=\sum_i d(q_i,q_{i+1})\,\omega(q_{i+1})$，$\omega(q)=1+\eta\, C_e(q)/C_{max}$；最后均匀重采样为 8 个归一化航点。$T_e^*$ 与 $C_e$ 仅用于训练，推理时无需分割与代价图。

**CE-Adapter（第 IV-D 节）**：ResNet 视觉分支各阶段经 FiLM 层注入机器人嵌入 $z_e$（$F_i^e=\gamma_i(z_e)\odot F_i+\beta_i(z_e)$，初始化近恒等使适配从预训练表示平滑起步）；初始轨迹经投影成 trace query，与具身条件视觉 token 做交叉注意力；残差头 $\Delta T_e=\delta_{max}\tanh(\mathrm{MLP}_{res}(Z_{trace}))$ 以 $\delta_{max}$ 限幅保住语义意图。两个辅助头：可通行性重建头从视觉 token 重建 $\hat C_e$（促使视觉分支编码具身专属地形 affordance）；具身敏感度头 $\alpha_e=\mathrm{Softplus}(\mathrm{MLP}_{sens}(z_e))$ 为不同具身加权代价惩罚。训练目标 $L_{CE}=L_{trace}+\lambda_{trav}L_{trav}+\lambda_{cost}L_{cost}+\lambda_{smooth}L_{smooth}$（权重 1.0/1.0/1.0/0.05），平滑项用二阶差分。CE-Adapter 在 62k 张经 CE-RRT\* 标注的导航图像上训练（单张 RTX 4090 约 3 小时）；VL-Tracer 微调 8×A100 约 48 小时，训练后冻结、不回传梯度。

## 四、实验与结果

**NaviTrace 基准（第 V-B 节，Table I）**：CrossTracer 总分 45.68，超 Gemini-2.5-Pro（35.67）10.01 分、超最强具身模型 Robobrain-2.5-8B（27.96）17.72 分；Claude Sonnet-4.5 仅 7.36、Qwen3-VL-8B-Thinking 为负分（-41.30），说明纯视觉推理不足以胜任具身条件轨迹生成。四类具身得分均匀：自行车 42.16 / 人类 46.26 / 腿式 46.40 / 轮式 46.28。消融：去掉 CE-Adapter 总分从 45.68 跌至 22.56（-23.12），其中 Accessibility 从 -3.18 升至 33.79、Social Norms 从 1.28 升至 37.87、Stationary Obstacle 从 25.23 升至 46.11——说明残差修正学到的正是物理落地能力。附加目标像素输入的变体达 63.91（不同输入设置，不与语言-only 直接可比）。

**实机部署（第 VI 节）**：轮式与腿式两平台（机载 Jetson Orin + 工作站 RTX 4090 经 WiFi 推理），4 项任务（室内白桌 / 米色沙发、二层平台「小心地滑」标识、户外带转弯的黑垃圾桶），每任务每平台每法 5 次。对照 OmniVLA：轮式平均 SR 0.40→0.65、SPL 0.37→0.59、STT 0.17→0.30；腿式 SR 0.45→0.70、SPL 0.31→0.58、STT 0.27→0.43。高层控制器跨方法保持一致，对比聚焦轨迹质量本身；实际执行路径较 OmniVLA 更贴近人类专家参考、目标附近收敛更平滑（Fig. 10）。

## 五、难点阐释

核心难点是「同一语义意图 × 不同物理约束」的组合爆炸：为每个平台人工标注可行轨迹代价高昂且无法穷尽场景。作者的巧思有两处。其一，把「修正」而非「生成」作为学习目标——初始轨迹已承载 VLA 的场景级语义结构，CE-Adapter 只需学局部残差（$\delta_{max}$ 限幅 + 平滑损失防止跑飞），小模型、小数据（62k 图、单卡 3 小时）即可胜任。其二，监督来源的自动化：CE-RRT\* 把「具身差异」编译成语义类别代价表（腿式的 $S_{free}$ 可含台阶、轮式的则不含），让经典采样规划在新范式里充当「无限标注员」——这与月刊曾深析的 RRT\* 形成有趣呼应：渐进最优性在这里的服务对象是像素空间监督的质量。FiLM 近恒等初始化也是细节巧思：适配器从预训练视觉表示出发渐进学调制，避免小数据下灾难性偏移。

## 六、延伸阅读

- NaviTrace（Hong et al. 2025）：定义「图像 + 指令 + 具身类型 → 2D 轨迹」评测协议的基准，本文的主战场与轨迹表示来源。
- VAMOS（VLM + affordance 候选重排）：像素空间候选路径接口的先行者，本文 VL-Tracer 的训练数据源与「候选选择」范式的对照面。
- OmniVLA（多模态目标 VLA 导航）：VL-Tracer 的底座架构与实机对比基线（去适配器即近似退化为它）。
