# Geometry-only Gaussian Splatting for Dense Monocular SLAM
## 一、概览

**GeoGS-SLAM：仅几何高斯泼溅的稠密单目 SLAM**（Geometry-only Gaussian Splatting for Dense Monocular SLAM）。作者来自北京航空航天大学仪器科学与光电工程学院。核心贡献：提出 **GeoGS（Geometry-only Gaussian Splatting）**——只保留位置、旋转、尺度、不透明度等几何参数、彻底去掉外观建模的高斯表示，并据此构建一套单目稠密 SLAM 系统；在 Replica / ScanNet++ / ScanNet / DTU 等基准上，在线建图效率与几何重建质量均优于现有 SOTA。

## 二、问题背景

稠密视觉 SLAM 需同时估计相机位姿并重建稠密三维地图，是机器人导航与避障的基础。3D Gaussian Splatting（3DGS）凭借显式高斯表示与可微光栅化在新视角合成上表现优异，逐渐被用于稠密 SLAM。但现有 3DGS 方法让每个高斯基元同时携带**颜色（外观）与空间（几何）属性**：作者指出，对 SLAM 而言**几何比外观更重要**——导航、避障依赖的是准确空间几何而非照片级渲染。外观-几何耦合带来两个痛点：（1）为降低光度误差而被保留的"漂浮"伪影几何并不精确，在线建图预算有限时几何优化被稀释；（2）回环或全局 BA 修正轨迹后，现有方法把视角修正逐基元传播到关联高斯，忽略空间一致性，相邻同面高斯可能收到冲突变换，产生"撕裂"与漂浮伪影。本文即针对这两点提出几何-only 表示与一致性地图更新。

## 三、方法要点（论文复述）

**A. GeoGS 基元。** 标准 3DGS 基元用球谐（SH）系数编码外观；GeoGS 仅保留几何相关参数：

$$G_i = \{\mu_i,\, s_i,\, q_i,\, \alpha_i\}$$

其中 $\mu_i \in \mathbb{R}^3$ 为位置，$s_i \in \mathbb{R}^2$ 尺度，$q_i \in \mathbb{R}^4$ 旋转（单位四元数），$\alpha_i$ 不透明度。由此每基元参数量下降 **80% 以上**，且无需外观建模，对光照变化更鲁棒、收敛更快。协方差矩阵由 $\Sigma_i = R(q_i)\,\mathrm{diag}(s_i)^2 R(q_i)^\top$ 给出。

**B. 深度与法向渲染。** 基于基元法向 $n_i = t_{x,i} \times t_{y,i}$（切向由旋转矩阵前两列给出），按 2DGS 方式在射线-泼溅交点处做可微渲染，得到深度图 $\hat D$ 与法向图 $\hat N$（原文式 14–15），供几何监督使用。

**C. 损失函数（无颜色监督下的几何优化）。** 由于去掉外观，常规颜色渲染损失不可用，作者设计单视角 + 多视角几何/光度监督：
- 单视角损失 $L_{\mathrm{single}} = \lambda_{nc}L_{nc} + \lambda_{ds}L_{ds} + \lambda_{dist}L_{dist} + \lambda_d L_d + \lambda_n L_n$（式 22）：法向一致性 $L_{nc}$（式 16，借 PGSR）、边缘对齐深度平滑 $L_{ds}$（式 18）、深度失真 $L_{dist}$（式 19）、以及对前端稠密深度/法向先验的 $L_1$ 损失 $L_d, L_n$（式 20–21）。
- 多视角损失 $L_{mv} = \lambda_1 L_1 + \lambda_{ssim}L_{ssim} + \lambda_{ncc}L_{ncc}$（式 30）：以渲染深度图将参考视角像素反投影到三维并重投影到目标视角，用有效掩码（视野内 + 遮挡一致性）筛选后，以 L1 / SSIM / 归一化互相关（NCC）提供跨视角光度监督（式 27–29）。
- 总几何损失 $L_{geo} = L_{\mathrm{single}} + L_{mv}$（式 31）。

**D. 局部平面驱动初始化。** 为加速增量建图下的几何收敛，对每个建图帧反投影点云做 KNN，用 PCA 估计局部平面：最小特征值对应特征向量为法向，平面度由特征值 $\lambda_0 \le \lambda_1 \le \lambda_2$ 比值给出；高斯旋转对齐到局部平面法向，低平面度邻域缩小尺度以限制不确定区的空间支撑。

**E. 一致性地图更新（回环/全局 BA）。** 轨迹经回环或全局 BA 修正后，不再把视角修正逐基元传播，而是对"被重访"的高斯区域施加一个**统一的 Sim(3) 变换**，将地图形变视为整体几何调整而非一堆逐视角位移，从而保留局部结构一致性、显著减少撕裂与漂浮伪影，使稠密地图与修正后轨迹对齐。

## 四、实验与结果

**实现**：工作站（Intel Xeon Gold 6342 + NVIDIA RTX 4090 24GB）；跟随 Splat-SLAM / HI-SLAM2，用 Omnidata 提取单目深度与法向先验；网格由渲染深度经 TSDF Fusion 融合得到；Adam 优化高斯参数。对比 NeRF 系（NICER-SLAM、GO-SLAM、NICE-SLAM、E-SLAM、GLORIE-SLAM、HI-SLAM）与 GS 系（MGS-SLAM、Splat-SLAM、GSO-SLAM、HI-SLAM2、DROID-SLAM、2DGS、PGSR、QGS）。

- **Replica（合成，8 序列，在线模式）**：GeoGS-SLAM 平均 Acc. **2.09 cm**、Comp. **3.95 cm**、Comp.Rat. **83.67%**，均优于 DROID-SLAM（3.33/8.49/69.77）、NICER/GO/HI-SLAM、Splat-SLAM（2.82/4.19/82.31）等（表 I）。
- **ScanNet++（真实，4 序列）**：ATE **4.41 cm** vs HI-SLAM2 4.81；CD **8.67 cm** vs 12.43（表 II）。
- **ScanNet（真实，8 序列，跟踪）**：平均 ATE **7.00 cm**，优于 NICE-SLAM 11.8、E-SLAM 10.6、GLORIE 7.50、Splat-SLAM 7.58、HI-SLAM2 7.06（表 III）。
- **Replica 跟踪（表 V）**：ATE **0.28 cm**，为所列方法最优（DROID 0.38、HI-SLAM2 0.32、GSO 0.46）。
- **DTU（多视，15 扫描，2 分钟优化预算）**：平均 CD **0.62 cm**，远优于 2DGS 1.38、PGSR 2.07、QGS 1.73（表 IV）。
- **模型效率（DTU Scan55，表 VI）**：仅需 **23k** 高斯、存储 **1.2 MB**、CD 0.34 cm，而 2DGS/PGSR/QGS 分别需 161k/231k/200k 高斯、37.5/54.6/8.1 MB。图 1 亦给出：GeoGS 基元参数量仅为标准 3DGS 的 17%，整图仅 28k 高斯（对比 2DGS 198k、PGSR 193k、QGS 107k）。

## 五、难点阐释

本文关键巧思在于**重新审视 3DGS 的设计前提**：对 SLAM 这类"几何即目的"的任务，外观建模是负担而非资产。剥离 SH 不仅省参、抗光照，更从根上消除了"为减光度误差而容忍几何漂浮伪影"的激励机制。第二个难点是**轨迹修正后的地图一致性**——这是 3DGS-SLAM 长期痛点（逐视角传播造成撕裂）。作者用统一的 Sim(3) 区域变换把"地图撕裂"转化为"整体几何对齐"，在工程上简单却直击要害。其贡献不在某个新模块，而在表示层面的取舍与系统级一致性策略，这正是它能在效率与质量上同时领先的原因。
